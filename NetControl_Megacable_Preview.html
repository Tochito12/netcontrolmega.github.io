Hallazgos de implementación

Resultados del proceso

01

Arquitectura integrada

La interfaz separa presentación, estilos y lógica JavaScript. El paquete incluye una estructura PHP/PDO y un esquema SQL para la fase de conexión al servidor.

02

Consistencia con OOHDM

Las clases CanalConexion, MetricaTrafico, Alerta, Incidencia, Reporte y Usuario corresponden con los módulos navegables de la aplicación.

03

Limitación identificada

Las cifras mostradas sirven para probar la interfaz. No hay conexión demostrada con datos de producción, autenticación real, ni despliegue público disponible en esta entrega.

Estado de publicación

Enlace del sitio

Publicación pendiente

La versión entregada se encuentra disponible como paquete descargable y puede abrirse localmente desde index.html. No se asigna una URL pública porque el proyecto no se ha desplegado en un hosting y no se cuenta con acceso autorizado a una cuenta de publicación. Para compartir una liga pública con la asesora, debe publicarse este directorio en un servidor estático o, para habilitar PHP y MySQL, en un servidor web configurado con dicha plataforma.
